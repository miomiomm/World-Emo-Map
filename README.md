🌍 世界情绪地图 World Emo Map
一个交互式的全球 Emo 乐队地图，覆盖 129+ 城市、230+ 支乐队。
🔗 在线访问: https://miomiomm.github.io/world-Emo-Map
功能
🗺️ 交互式世界地图 — 点击城市标记探索当地 Emo 乐队
📅 年份滑块 — 筛选 1983–2025 年间成立的乐队
🏷️ 子流派筛选 — Emocore / Midwest / Screamo / Emo-Pop / Pop-Punk / Post-HC / Math / Indie / Revival
📍 城市详情面板 — 按成立年份排序的乐队列表
📱 响应式设计 — 手机、平板、桌面端自适应
数据来源
乐队数据来自 Discogs、RateYourMusic、Bandcamp 及各类音乐资料库，涵盖第一波 Emocore 到第五波 Hyper-Online 的历史。
技术栈
纯 HTML + CSS + JavaScript
SVG 手绘世界地图
GitHub Pages 免费托管
如何贡献
发现遗漏的乐队？欢迎提交 PR 或直接发 Issue！
